# Анкета дилера БАЗ — сайт

Статический сайт АО «Романов» для кандидатов в дилеры БАЗ: HTML, CSS, JS и картинки.
Сервер, база данных и PHP не нужны. Анкета заполняется в браузере, черновик хранится там же.

После заполнения сайт сам собирает в браузере два файла (и архив с ними):

| Файл | Формат | Что внутри |
|---|---|---|
| Анкета кандидата | .pptx | анкета в фирменном стиле: обложка, 00 Заявка, 01–07 по разделам формы; отдельный слайд на каждый дилерский центр и шоурум |
| План продаж 2026 | .pdf | бланк на одной странице A4: все модели по группам и месяцам, итоги, авансирование, подпись |

Кандидат отправляет анкету и план письмом на b.chestnov@baz.ru.

## Состав

```
index.html                   страница с анкетой
404.html                     страница «не найдено»
favicon.ico, robots.txt
.nojekyll                    нужен для GitHub Pages
assets/css/style.css         стили
assets/js/app.js             логика формы, проверка полей, черновик, скачивание и архив
assets/js/fill.js            ZIP-упаковщик (там же код чек-листа Word, сейчас не используется)
assets/js/deck.js            анкета PowerPoint (генерируется с нуля, 16:9)
assets/js/planpdf.js         план продаж PDF (свой генератор PDF со встроенным шрифтом)
assets/data/regions.js       карта регионов России для блока «Регионы присутствия»
assets/data/deck-assets.js   иллюстрация обложки и логотипы для анкеты
assets/data/plan-pdf-assets.js  шрифт Liberation Sans (подмножество, SIL OFL 1.1) и логотипы для PDF
assets/img/                  логотипы, иллюстрация шапки (hero.svg), фото техники, иконки
Иллюстрации/11111м_СБ.ai     исходник иллюстрации (Illustrator), на сайт не загружается
```

## Публикация

**GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
Адрес: `https://<аккаунт>.github.io/dealerform/`.

**Netlify:** app.netlify.com/drop — перетащить папку с сайтом.

**Yandex Object Storage** (российские серверы): бакет с публичным доступом, режим «Веб-сайт»,
главная `index.html`, ошибка `404.html`.

Сайт работает и локально — достаточно открыть `index.html` двойным щелчком.
